# Neuro Life

A small artificial life simulation written in Python.

The goal of the project is to experiment with:
- game/simulation loops
- autonomous agents
- neural networks
- evolution and learning
- visualization of agent behavior

## Stack

- Python
- Pygame
- NumPy

## Current state

Basic Pygame application with:
- window initialization
- event loop
- FPS limiting

## Run

Create and activate a virtual environment, install the project:

```bash
pip install -e ".[dev]"
python src/neuro_life/main.py
